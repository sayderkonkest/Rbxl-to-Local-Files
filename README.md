Rblx-to-Local-Files is a software to export your **.rbxl** file to separate local files.

Tips:
1. Separate the service names with a space
2. If you type "all" in the services list, it will export all services visible in the Roblox Studio explorer

Example video (Youtube): [Exporting .rbxl to local files](https://www.youtube.com/watch?v=IsrgzlDgMc8)
