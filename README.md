Rblx-to-Local-Files is software written in Luau to transform your **.rbxl** file into local files.

Tips:
1. You should separate the service names with a space
2. If you type "all" in the services section, it will convert all services visible in the Roblox Studio explorer.

Example video: https://www.youtube.com/watch?v=umbHd09k0q8
